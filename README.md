# Fn 协同控制台 UI

一个纯前端的协同工作台界面示例，包含任务面板、成员状态、笔记记录等模块，可用于演示或进一步扩展。

## 使用方式

1. 在任意静态服务器环境下打开 `index.html`（例如使用 VS Code Live Server 或 `python -m http.server`）。
2. 通过左侧导航查看不同的界面状态，支持亮暗主题切换。
3. 点击「新增任务」可添加新的任务条目，底部「协作笔记」支持记录实时笔记。

## 文件结构

- `index.html`：页面结构与模板
- `styles.css`：全局样式与暗色模式支持
- `app.js`：基础交互逻辑（任务新增、笔记记录、主题切换）
